## 安装与更新

安装包：完整解压 ZIP，找到包含 `manifest.json` 的 `feishu-original-tts` 文件夹。源码安装请先按仓库根目录 README 下载资源并构建，加载目录为 `extension/`。

首次安装：使用 Chrome 135 或更新版本，打开 `chrome://extensions/`，启用开发者模式，使用「加载已解压的扩展程序」选择上述文件夹。如果还安装着旧目录的版本，请停用旧版，保留一个版本。安装后保留该文件夹。

更新：在扩展管理页刷新「飞书原文朗读」，再刷新飞书网页。本版使用扩展后台音频页面和本地 WASM 推理。

扩展更新或停用会使已打开页面的旧连接失效。本版会停用旧播放器并显示「刷新页面」，点击后加载新上下文。更新扩展文件仍需先在扩展管理页重载扩展，再刷新飞书页面。

## 使用

- 飞书站点 `*.feishu.cn` 自动加载脚本；云文档正文出现后，底部播放器自动显示，无需点击扩展图标。
- 页面加载时不扫描全文、不自动发声。第一次点击播放时读取并缓存全文。
- 中间三个按钮为上一句、播放/暂停、下一句。暂停、跳句、切换起点都复用本页缓存。
- 进度条使用当前字符 / 全文字符近似计算，可以点击或拖动。播放中跳转继续播放，暂停时跳转保持安静。
- 声音和语速都是直接下拉菜单，选中即生效。菜单向上展开，使用浏览器顶层渲染，位于进度条之上。
- 「选起点」后点击正文中的词，直接从那里开始。拖选正文后可「只读选区」。
- 默认跟随：将当前播放位置上下居中。手动滚动正文进入自由浏览，播放和进度继续更新。
- 自由浏览时，播放器上方水平居中显示「回到跟随」。点击后当前播放位置重新居中，按钮立即隐藏。
- 暂停使用主播放按钮。
- 右侧刷新图标可重新读取已经缓存的正文。

浅蓝色标记当前句，较深蓝色标记当前词；保留原有表格、链接和排版。使用 Kokoro v1.1-zh 的中文女声、男声和英文音色。模型在独立 Worker 内按句生成音频，播放当前句时顺序预生成后续缓冲。首次播放需等待模型加载和当前句合成；自然换句复用已完成的音频。如果设备生成速度跟不上播放速度，下一句仍需等待生成完成。

## 缓存边界

缓存位于当前页面内存。正常虚拟滚动加载和卸载段落不使缓存失效。当前播放段落离开渲染区时仅停止该段高亮，继续使用缓存正文播放；重新渲染后恢复高亮。正文编辑器临时卸载也保留当前播放和缓存。正文编辑或已呈现段落发生内容变化后，下次播放会重新读取；刷新网页或切换文档也会重新读取。尚未呈现的远端改动不能提前比较，可手动刷新缓存。

音频缓存位于扩展播放页面。全文缓存并分句后，计算朗读队列句长的均值和总体标准差，取 `ceil(mean + std)` 为统计缓冲下限（n = 1）；只读选区时仅统计选区，统计值在本次队列内固定。从当前句之后依次累计非空白字符数，直到达到 `max(统计下限, 紧接着的未缓存句字数)`，或到达文末、选区末尾。当前播放句参与句长统计，播放剩余字数不计入缓冲；标点按字符计，Unicode 补充字符计一个字符。

例如句长为 `10、5、4、100` 或 `1、1、1、1、1、1、1、100` 时，初始预生成范围会包含末尾的 100 字句。更长的短句序列可能先攒够统计下限，再随播放推进补充后续内容。该规则是按字数估算的预生成目标，首次生成及补充缓冲期间可能尚未达到目标，也不能保证所有设备与语速下都没有等待。

每次换句重新计算预生成目标，复用尚未播放的缓存并释放已播放音频。暂停时可以继续填满目标缓冲。跳句、换起点、换音色或语速、正文变化及切换文档会清空旧音频队列，取消结果不会混入新播放。只读选区时不会提前生成选区外的内容。预生成失败会明确显示错误并停止本次朗读。

图片、画板、嵌入式电子表格和公式语音化未适配；折叠内容需先展开。词时间戳来自 ONNX 模型的 `duration` 输出（每帧 600 个采样，24 kHz），按实际音频时钟触发高亮。它属于模型预测的边界，尚未做人工逐词对齐精度评测。中文分词与英文读音使用 JavaScript 前端，部分多音字、专有名词的读法可能与官方 Python Demo 不同。

## 本地语音资源

当前打包 5 个音色：清禾 · 女（`zf_001`）、云川 · 男（`zm_010`）、Maple · 女 · 美式英语、Sol · 女 · 美式英语、Vale · 女 · 英式英语。清禾、云川是插件提供的本地昵称，官方 v1.1-zh 中文音色使用编号；底层音色 ID 和已保存的声音选择保持一致。

官方 [v1.1-zh 音色目录](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh/tree/main/voices)提供 100 个中文编号音色与 3 个英文音色。Xiaobei、Xiaoni、Xiaoxiao、Xiaoyi、Yunjian、Yunxi、Yunxia、Yunyang 列在 [v1.0 音色表](https://huggingface.co/hexgrad/Kokoro-82M/blob/main/VOICES.md)，当前插件未包含这些音色。

使用 [Kokoro v1.1-zh ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.1-zh-ONNX)。量化版本在本机 WASM 实测输出 NaN，因此本版使用 FP32 模型（约 339 MB），运行库和五个音色另外占用空间。无需安装 Python 或 PyTorch。模型随扩展打包，播放时无需下载资源。

源码、许可证及中文前端修改说明见 [THIRD_PARTY.md](THIRD_PARTY.md)。资源的固定版本、大小和 SHA-256 见 `assets-manifest.json`。

## 设计依据

[飞书 Universe Design 概述](https://open.feishu.cn/document/design-specification/written-in-advance)

- [色彩](https://open.feishu.cn/document/design-specification/design-language/color)：品牌色 `#1456F0`；正文 `#1F2329`、次级文字 `#646A73`、辅助文字 `#8F959E`。
- [字体](https://open.feishu.cn/document/design-specification/design-language/font)：正文 400、强调 500。
- [选择器](https://open.feishu.cn/document/design-specification/component---data-entry/select)：直接单选、展示当前值、选择后收起，底部空间不足时向上展开，列表建议最大高度 246px。
- [滑动输入条](https://open.feishu.cn/document/design-specification/component---data-entry/slider)：区分已读和未读轨道，点击或拖动并即时反馈数值。

使用原生控件和 Shadow DOM 实现，未引入 Semi React 组件运行库。[Semi Design](https://semi.design/zh-CN/) 的飞书主题作为辅助参考；当前色彩以飞书官方规范为准。
