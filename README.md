# 飞书原文朗读

Chrome Manifest V3 扩展。直接在飞书原页面朗读与高亮，使用本地 Kokoro v1.1-zh 中英文语音。

## 功能

- 在浏览器 CPU 上通过 ONNX Runtime Web / WASM 合成语音，无需 Python、GPU 或语音 API Key。
- 保留飞书原文排版，支持按句播放、选区朗读、调整语速、切换音色和跟随滚动。
- 使用模型音素时长生成原文词时间戳，按实际音频时钟同步高亮。
- 播放当前句时预生成后续音频，减少换句等待。

当前版本 **0.5.4**，最低支持 **Chrome 135**。中文 FP32 模型约 339 MB，运行库和音色额外占用空间。源码仓库不包含模型、音色二进制和构建产物，按下方步骤下载并构建后即可加载。

## 从源码安装

准备 Node.js 22 或更新版本，以及系统 `zip` 命令（仅打包 ZIP 时需要）。

```sh
git clone https://github.com/liuzhao1225/feishu-original-tts.git
cd feishu-original-tts
npm ci --registry=https://registry.npmmirror.com
npm run assets
npm run build
```

1. 在 Chrome 地址栏打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本项目的 `extension/` 文件夹。
3. 打开或刷新飞书云文档，点击底部播放器。首次播放需要等待模型加载和第一句合成。

保留扩展文件夹。更新代码并重新构建后，在扩展管理页重新加载，再刷新飞书网页。

资源下载默认使用 Hugging Face 镜像，所有文件按固定版本和 SHA-256 校验。也可指定官方源：

```sh
KOKORO_ASSET_SOURCE=https://huggingface.co npm run assets
```

构建及下载过程需要网络。语音合成在本地完成，朗读正文不发送到外部语音服务；飞书网页本身仍需要正常登录和文档访问权限。

## 已知边界

- 首次生成需要等待；设备生成速度跟不上播放速度时，换句仍会等待。
- 时间戳来自模型预测，尚未进行人工逐词对齐精度评测。
- 图片、画板、嵌入式电子表格和公式语音化尚未适配，折叠内容需先展开。
- 中文多音字和专有名词可能读错；本项目为独立社区项目。

## 0.5.4

- 建立朗读队列后计算句长的均值和总体标准差，以 `ceil(mean + std)` 为缓存字数下限。缓冲还须覆盖紧接着的未缓存句子，连续短句不会把目标压低到一两字。
- 当前句之后按顺序预生成，直到累计字数达到 `max(统计下限, 下一未缓存句字数)`，或到达朗读范围末尾。统计值在本次队列内固定，换句时保留未播放的音频与正在生成的句子。

## 0.5.3

- 预生成句数按字数动态调整：后续缓存句子的非空白字符总数达到再下一句的字符数时停止扩展；当前播放句不计入缓冲。
- 每次换句重新计算，复用未播放的缓存并释放已播放音频。文末和选区末尾只缓存范围内剩余内容。

## 0.5.2

- 音色菜单显示名字和性别。`zf_001`、`zm_010` 的本地昵称为清禾、云川；Maple、Sol、Vale 保留原名并显示女性及英语口音。

## 0.5.1

- 修复换句时「整句中点 → 首词」切换导致的上下回跳：始终以当前朗读位置所在行居中。
- 词间停顿时保留跟随位置；跨行词使用起始字符定位，清除词高亮不会重新居中整句。

## 0.5.0

- 播放当前句时，用同一个模型 Worker 顺序预生成后两句，音频和词时间戳一起缓存；自然换句直接复用，播完的音频释放。
- 暂停时保留当前句与最多后两句。跳句、换起点、换音色或语速、正文变化和切换文档时重新建立音频队列；暂停时换声音仍保持暂停。
- 修复 `①`–`⑳` 圈号序号的朗读，保留圈号字符在原文中的高亮位置。

## 0.4.2

- 修复英文及中英混排中 `teacher`、`computer` 等词触发「模型词表缺少音素：ɚ」：按 Misaki 规则将卷舌央元音映射为 `əɹ`，保留完整原词的时间戳与高亮位置。

## 0.4.1

- 扩展更新或停用后，旧播放器显示明确的刷新页面入口并停止调用失效接口。
- 普通连接断开时，可主动点击播放重新连接；缓存继续保留。

## 0.4.0

- Kokoro v1.1-zh 在插件内通过 ONNX Runtime Web / WASM 运行，支持中英文与混合文本。
- 使用模型的音素时长输出生成词时间戳，再按音频播放时钟高亮原文；数字展开保留原始字符位置。
- 默认跟随播放，当前播放位置位于可见正文区域的垂直中央。
- 播放时手动滚动进入自由浏览，不再自动调整滚动位置。
- 自由浏览时，「回到跟随」悬浮在播放器上方水平中央；点击恢复跟随后立即隐藏。
- 飞书虚拟列表卸载当前段落时，缓存正文和播放继续；该段重新渲染后恢复高亮。
- 首次播放才读取全文、加载模型。暂停、跳句、切换起点复用缓存。

## 开发

- `extension/`：扩展源码，下载资源并构建后可加载。
- `tests/core.test.cjs`：字符偏移、段落顺序和缓存判断。
- `tests/fixture.html`、`tests/ui-scenarios.js`：浏览器交互验证，模拟扩展消息和 TTS 词事件，不发声。
- `scripts/package.cjs`：复制扩展并生成 ZIP，默认输出到 `dist/`。

运行依赖为本地 JavaScript、ONNX Runtime Web 和 WASM，最低 Chrome 135。无需 Python、PyTorch、本地服务或在线语音 API。模型和音色随扩展打包，正文不发送到外部服务。

```sh
npm ci --registry=https://registry.npmmirror.com
npm run assets
npm test
npm run check
npm run package
```

浏览器验证：确认 18941 端口空闲后运行 `node tests/serve.cjs`，打开 `http://127.0.0.1:18941/`，点击「运行交互检查」。该页模拟语音事件，验证缓存、跟随、自由浏览和虚拟卸载。`/runtime.html` 使用真实 Worker、WASM 和播放器，检查中英文合成、暂停恢复和词事件。`node scripts/smoke.mjs` 在 Node 中运行同一 WASM 引擎，生成 `work/smoke/` 音频与时间戳。

`/prefetch-runtime.html` 使用真实模型验证动态字数缓冲、每句仅生成一次、连续播放和圈号词高亮。`tests/prefetch.test.mjs` 与 `tests/background.test.cjs` 检查缓冲窗口、未完成的推理复用、取消、暂停换音色及跨文档消息隔离。

`/follow-runtime.html` 使用多行正文和模拟词事件，检查换句、首词、词间停顿、跨行词及自由浏览切换时的滚动位置。

## 安装与发布

在 `chrome://extensions/` 启用开发者模式，「加载已解压的扩展程序」选择 `extension/`。更新后刷新扩展卡片与飞书网页。保留单个安装目录，避免重复播放器。

打包到自定义输出目录：

```sh
node scripts/package.cjs ./outputs
```

详细使用方式、缓存边界和设计来源见 [extension/README.md](extension/README.md)。
